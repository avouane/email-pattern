# Email Builder

Simple Java project that demonstrates the Builder Pattern.

## Classes

* `Email` — email object.
* `EmailBuilder` — builder interface.
* `EmailObjectBuilder` — creates an email.
* `EmailPreviewBuilder` — creates an email preview.
* `EmailDirector` — creates ready email templates.
* `Main` — example of using the builders.

## How to Run

Open the project in IntelliJ IDEA and run `Main.java`.

## Example

The project can create a welcome email and display it as an object or as a text preview.
